# Frank OS Portfolio

Frank OS is a vanilla HTML, CSS, and JavaScript personal developer portfolio for Frank Banda. It presents portfolio content as a desktop-style operating system with app windows, a lock screen, boot screen, terminal commands, Cyber Lab simulations, mini games, local notes, a file explorer, settings, achievements, and responsive mobile app panels.

## Files

- `index.html` - main document shell
- `css/style.css` - all layout, theme, animation, and responsive styling
- `js/script.js` - app data, window manager, terminal, browser, search, settings, and form logic
- `assets/images/` - project thumbnails
- `assets/audio/` - optional folder for your own music files
- `assets/Frank-Banda-CV.pdf` - placeholder CV file used by download buttons

## Run

Open `index.html` directly in a browser. No build step, package manager, or framework is required.

## Edit

- Update project data, skills, education, and journey items in `js/script.js`.
- Replace placeholder project/social actions with real links when available.
- Replace `assets/Frank-Banda-CV.pdf` with the final CV.
- Notes, achievements, settings, scores, and icon positions are saved in the visitor's browser using LocalStorage.

## Shortcuts

- `ESC` - close the active window, or exit Matrix Mode
- `Ctrl + K` - focus global search
- `Ctrl + Alt + T` - open Terminal
